## What's New (v1.0.0)
- **110+ Provider Presets:** Expanded catalog featuring specialized, local, and frontier APIs.
- **Enhanced API:** Added STT audio/transcriptions and native /v1/models/{model_id} support.
- **Improved Routing:** Advanced cross-protocol translation and smarter fallback logic.
- **Refined UI:** Next-gen dashboard enhancements.

## Install on Windows
1. Download and extract the source ZIP (or clone the repository).
2. Run install.bat once.
3. Run start.bat.
